# Roadmap

This roadmap records possible directions, not promised release dates.

## Near term

- Expand mathematical unit tests, including exact-grid and phase-wrap edges.
- Add component and browser tests for keyboard use and responsive layouts.
- Add visible focus styling checks and automated accessibility checks.
- Self-host fonts or remove the runtime font dependency.
- Add screenshots captured from a verified release.

## Learning depth

- Give each of the ten topics a dedicated experiment and checkpoint.
- Add prediction prompts before revealing an outcome.
- Explain incorrect assessment answers.
- Add a superposition-of-eigenstates lesson with a multi-peak distribution.

## Mathematical depth

- Introduce explicit complex-number, vector, and matrix types.
- Add Hermitian validation and small-matrix diagonalization.
- Implement complete control-register amplitude transforms.
- Compare the calculated shortcut against a small exact state-vector path.
- Declare and test exact versus analytical execution modes.

## Project maturity

- Add release automation and tagged release notes.
- Add Firefox and WebKit browser coverage.
- Add a documented visual-regression workflow.
- Define a public maintainer contact and private conduct-reporting channel.

Proposals should begin with the learner outcome and include the mathematical
invariant or acceptance check that will verify the result.
